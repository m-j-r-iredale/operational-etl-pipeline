# Sample Data

`fake_audit_logging_spreadsheet.xlsm` is a fictional workbook created to demonstrate the audit ETL workflow.

It mirrors the structure of the operational process used by the project whilst containing no real customer or operational data.

The workbook includes examples of:

- completed cases
- incomplete cases
- missing required values
- inconsistent text formatting
- multiple account numbers within a single row
- persistent UUID values used as transaction identifiers
